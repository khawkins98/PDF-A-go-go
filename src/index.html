PDF-A-go-go

An embeddable PDF viewer built on PDF.js. Include one JS file, add a div with data-* attributes, and you're done.

Zero Config Accessible Mobile Ready Search Fullscreen
HTML 
<div class="pdfagogo-container"
  data-pdf-url="./pdf-a-go-go-showcase.pdf"
  data-default-page="1"
  data-show-toolbar="true"
  data-show-search="true"
  data-show-page-selector="true"
  data-show-current-page="true"
  data-show-download="true"
  data-show-fullscreen="true"
  data-show-share="true">
</div>

<script src="pdf-a-go-go.js"></script>
