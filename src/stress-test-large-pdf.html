🚀 PDF-A-go-go Large PDF Stress Test

This page tests the performance and memory handling of PDF-A-go-go with a very large PDF document (example_large.pdf, 827 pages, 5.4MB). Debug mode is enabled to monitor real-time performance metrics.

Document Size 827 pages, 5.4MB
Debug Mode Enabled (see top-right corner)
Zoom Support Full range (25% - 500%)
Memory Management Automatic cleanup enabled

📋 Testing Instructions

  • Scroll Performance: Scroll through the document and observe debug metrics in top-right
  • Memory Usage: Watch "Memory Freed" metric to see garbage collection in action
  • Rendering Speed: Note "Avg High-Res" times (should be under 500ms per page)
  • Page Navigation: Use arrow keys, Page Up/Down to test navigation
  • Large Document Handling: Jump to different sections and observe performance

🔍 Zoom Testing

Focus the PDF first (click on it), then:

  • Ctrl + Plus / Ctrl + = to zoom in
  • Ctrl + Minus to zoom out
  • Ctrl + 0 to reset zoom
  • Ctrl + Mouse Wheel for smooth zooming
  • Touch devices: Pinch to zoom
