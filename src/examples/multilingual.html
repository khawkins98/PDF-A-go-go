Multilingual

Every label in the viewer — button tooltips, screen-reader announcements, search and error text — can be translated. Pick a language below and the whole interface switches. German ships as a bundled pack (data-locale="de"); French here is supplied as a custom set of strings, so any language works without waiting for a bundled pack.

Tip: open the toolbar tooltips, run a search, or expand the keyboard-shortcuts panel to see the labels change.
